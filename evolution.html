Where HTTP Came From

HTTP was created as part of the development of the World Wide Web. Tim Berners-Lee developed the early web while working at CERN. The early web brought together technologies such as HTML, URLs, and HTTP so that people could access and share information.

The first version of HTTP was very simple because early websites were mostly basic text documents. As websites became more complex, HTTP had to change to support the growing needs of the web.

HTTP/0.9 and HTTP/1.0

HTTP/0.9

HTTP/0.9 was the earliest version of HTTP. It was designed for a very simple web and mainly allowed a client to request an HTML document from a server. It did not include many of the features found in modern HTTP.

HTTP/1.0

HTTP/1.0 added more features to web communication. It supported additional request methods, status codes, headers, and different types of content. HTTP/1.0 was documented in RFC 1945 in 1996.

HTTP/1.1

HTTP/1.1 was introduced in 1997 and became an important version of HTTP for the growing World Wide Web. One major improvement was the ability to reuse connections instead of creating a completely new connection for every request.

HTTP/1.1 also improved features such as caching, hosting multiple websites on one server, and transferring data. These improvements helped HTTP support websites that were becoming larger and more complicated.

HTTP/2

HTTP/2 was introduced in 2015 to improve web performance. Modern webpages often need many files, such as HTML, images, style sheets, and other resources.

One important feature of HTTP/2 is multiplexing. Multiplexing allows multiple streams of information to share one connection. HTTP/2 also introduced features such as header compression and binary framing to make communication more efficient.

HTTP/3

HTTP/3 is the newest major version covered in this project. HTTP/1.1 and HTTP/2 use TCP for their connections, while HTTP/3 uses a newer transport protocol called QUIC.

QUIC supports multiple independent streams and was designed to improve the speed and reliability of web communication. It can also help maintain a connection when a device changes networks, such as moving from Wi-Fi to a cellular network.

Comparing HTTP Versions

The table below shows some of the major differences between HTTP/1.1, HTTP/2, and HTTP/3.
