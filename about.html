About the Project

This website was created for IT 3203 as part of a web development project. The topic of the project is the evolution of HTTP, which stands for Hypertext Transfer Protocol.

The project explains how HTTP works and how it developed from the early versions of the protocol to HTTP/1.1, HTTP/2, and HTTP/3. It also covers important concepts such as clients, servers, requests, responses, HTTPS, TLS, and QUIC.
