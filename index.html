What Is HTTP?

HTTP stands for Hypertext Transfer Protocol. It is a set of rules that allows web browsers and servers to communicate with each other. When you visit a website, your browser sends an HTTP request to a server. The server then sends an HTTP response containing the information needed to display the webpage.

HTTP has changed significantly since the beginning of the World Wide Web. Early versions were designed for simple webpages, while modern versions such as HTTP/2 and HTTP/3 are designed to handle today's faster and more complex websites. This project explores how HTTP works, how it has evolved, and why those changes matter.

Key Terms

Understanding these terms will make it easier to learn how HTTP works and how it has evolved over time.

  • HTTP: Hypertext Transfer Protocol, the set of rules used by web browsers and servers to communicate.
  • Client: A device or application, such as a web browser, that requests information from a server.
  • Server: A computer or system that receives requests and provides webpages, files, or other resources.
  • Request: A message sent by a client asking a server for a resource or action.
  • Response: The message a server sends back after receiving and processing a request.
  • HTTPS: HTTP protected by TLS to provide secure communication between a client and server.
  • TLS: Transport Layer Security, a security protocol that encrypts data traveling between a client and server.
  • QUIC: The transport protocol used by HTTP/3 to provide faster and more reliable web communication.
