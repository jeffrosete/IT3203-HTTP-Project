Research Sources

The following sources were used to research HTTP, its history, security, and the development of modern versions of the protocol. These resources can also be used to learn more about HTTP and web development.

  • Berners-Lee, T., Fielding, R., & Frystyk, H. (1996). Hypertext Transfer Protocol - HTTP/1.0 (RFC 1945). RFC Editor
  • Fielding, R., Nottingham, M., & Reschke, J. (2022). HTTP Semantics (RFC 9110). RFC Editor
  • Fielding, R., Nottingham, M., & Reschke, J. (2022). HTTP/1.1 (RFC 9112). RFC Editor
  • Thomson, M., & Benfield, C. (2022). HTTP/2 (RFC 9113). RFC Editor
  • Bishop, M. (2022). HTTP/3 (RFC 9114). RFC Editor
  • Iyengar, J., & Thomson, M. (2021). QUIC: A UDP-Based Multiplexed and Secure Transport (RFC 9000). RFC Editor
  • Rescorla, E. (2018). The Transport Layer Security (TLS) Protocol Version 1.3 (RFC 8446). RFC Editor
  • Mozilla Developer Network (MDN). HTTP: Hypertext Transfer Protocol. MDN Web Docs
  • Mozilla Developer Network (MDN). Evolution of HTTP. MDN Web Docs
  • Zheng, J. G. (2026). Introduction to Web Development, IT 3203. Course lecture materials.
